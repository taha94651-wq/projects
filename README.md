# Mostafa Taha — Portfolio

موقع بورتفوليو شخصي (عربي / إنجليزي) — HTML و CSS و JavaScript من غير مكتبات أو خطوات بناء، ومعاه لوحة تحكم (Pages CMS) للتعديل من غير كود.

## الملفات

| الملف | الوظيفة |
|---|---|
| `content/projects.json` | المشاريع (تصميم / تنفيذ) |
| `content/ai.json` | شغل الذكاء الاصطناعي |
| `content/site.json` | البيانات الشخصية، الخبرات، المهارات، البرامج، اللغات |
| `assets/` | الصور والفيديوهات والـ CV |
| `.pages.yml` | إعدادات لوحة التحكم |
| `index.html`, `styles.css`, `app.js` | الشكل والبرمجة |

## لوحة التحكم (التعديل من غير كود)

**إعداد لمرة واحدة:**
1. ادخل على <https://app.pagescms.org> وسجّل دخول بحساب GitHub.
2. اسمح لـ Pages CMS بالوصول للريبو `projects`.
3. اختار الريبو والفرع اللي الموقع بيتنشر منه (`main`).

**بعد كده:** افتح `رابط-الموقع/#/admin` — هيحولك للوحة التحكم مباشرة. الزوار مش بيشوفوا أي زرار أو لينك ليها، ومحدش يقدر يعدّل غير اللي معاه صلاحية على الريبو.

أي تعديل بتعمله بيتحفظ في الريبو، والموقع بيتحدث لوحده خلال دقيقة أو اتنين.

## خانات المشروع

- **Section — القسم:** تنفيذ، تصميم، أو الاتنين.
- **Project type:** متاجر / صالات رياضية / سكني / مكاتب / ضيافة ومطاعم / فعاليات — ده الفلتر جوه كل قسم.
- **Status:** تم التنفيذ / قيد التنفيذ / تصميم فقط.
- **My role — phases:** علّم على المراحل اللي عملتها — بتظهر في صفحة المشروع كخط مراحل، والمراحل اللي عملتها منورة بالذهبي.
- أي خانة تسيبها فاضية مش بتظهر، وأي صورة فاضية بيظهر مكانها صورة مؤقتة.

## اللينكات

- بالإنجليزي: `…/?lang=en` — بالعربي: `…/?lang=ar`
- مشروع معين: `…/#/p/assaf-perfumes`
- لوحة التحكم: `…/#/admin`

## التشغيل على جهازك

الموقع بيقرا ملفات JSON، فلازم يتفتح من سيرفر (مش بالدبل كليك على `index.html`):

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```
